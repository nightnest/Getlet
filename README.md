# GETLET website

A static, multi-page website for **GETLET**, a UK lettings and property management business. Plain HTML, CSS and vanilla JavaScript, generated by a tiny zero-dependency Node build script so the header, footer and cookie banner are shared with no copy-paste drift.

## Run locally

Requires Node 18+. No `npm install` needed (there are no dependencies).

```bash
node build.js        # builds ./dist (plain static HTML)
node serve.js 8080   # serves ./dist at http://localhost:8080
# or: npm start      # build + serve
node _tools/check.js # QA: links, assets, titles, meta, h1, forbidden claims
node _tools/check.js --external   # also checks external links
```

`dist/` can be opened by any static host (Netlify, GitHub Pages, Cloudflare Pages, S3). Links are root-relative (`/services/`), so deploy at the domain root, or set `site.basePath` in `site-config.json` (for example `/getlet/`) and rebuild.

## Replace business details

Edit **`site-config.json`**, then run `node build.js`.

- `site.serviceArea` drives the "[town]" wording across the site (default: "your local area").
- `contact.*` (address, phone, email, hours, complaints contact): empty means hidden or "[To be confirmed]".
- `social.*`: footer icons appear only when a URL is set.
- `placeholders.*`: fees, repair-authority limits, 24-hour definitions, payment details. Empty values render a styled "[To be confirmed]" tag; filling one in replaces it everywhere it is used.
- `team`: reserved for real people; the About page shows a "to be added" block until then (no fake staff photos).
- `site.siteUrl`: used for canonical URLs, sitemap, Open Graph. **Replace the example.com placeholder before launch.**
- `structuredData.localBusinessEnabled`: keep `false` until a real address and phone are in the config.

To replace images: add files named `key-480.webp`, `-800`, `-1280`, `-1920` and `key-1280.jpg` to `assets/images/`, add the key to `assets/images/manifest.json`, and use `{{img:key|sizes}}` in a page.

## Forms

No backend exists, so by default (`forms.mode = "live"` with the Formspree endpoint in `forms.endpoint`) a valid submission is POSTed to Formspree (`https://formspree.io/f/moeekozy`), which emails the leads inbox. Success is shown only on a successful response. Setting `forms.mode` to `email` falls back to opening the visitor's email app addressed to `forms.leadsEmail`.

To submit directly instead, set in `site-config.json`:

```json
"forms": { "mode": "live", "endpoint": "https://formspree.io/f/xxxxxxx" }
```

The success message then appears **only** when the endpoint returns a successful HTTP response; otherwise the visitor sees a failure message. Works with Formspree, Netlify Forms or a custom API accepting a multipart POST. Before enabling: review the privacy notice, keep the marketing tick box separate and unticked, and make sure the endpoint is covered by a data-processing agreement.

Fields sent: the visible fields, a non-identifying `reference`, `utm_source`, `utm_medium`, `utm_campaign`, `source_page`. The honeypot field `website` is stripped.

## Analytics (GA4) and cookie consent

Set `analytics.gaMeasurementId` (for example `G-XXXXXXXXXX`). If it is empty, nothing is loaded. When set, GA4 loads **only after** the visitor accepts analytics in the cookie banner (accept, reject and manage have equal prominence; nothing pre-ticked; the choice is remembered; storage access is wrapped in try/catch).

Events pushed through `window.GT.track()` (never any name, email, phone, address or free text): `landlord_enquiry` (also sent as `generate_lead` with `audience_type=landlord`), `tenant_viewing_request`, `repair_report`, `form_start`, `form_submit_success`, `phone_click`, `plan_comparison_used`, `statement_example_viewed`, `cta_click` (with `cta_id`). Events carry a `method` parameter (`mailto` or `endpoint`). In GA4, mark `generate_lead` as a key event.

### UTM convention

Tag every link you share: `?utm_source=facebook&utm_medium=organic_social&utm_campaign=landlord_repairs`. Source, medium and campaign are kept for the session and written to hidden form fields so enquiries can be traced to a campaign. Suggested values: `source` = facebook / instagram / tiktok / google / rightmove / zoopla / referral; `medium` = organic_social / cpc / portal / referral / email; `campaign` = short snake_case name.

## Honesty rules built in

No invented fees, counts, testimonials, awards, scheme memberships or properties; no competitor names or prices; portal costs (Rightmove/Zoopla) are not published; no "guaranteed"; the 24-hour standard is "GETLET's stated service standard"; compliance copy is dated, England-only and links to GOV.UK; no payments or client login are implied. `node _tools/check.js` scans the built pages for forbidden claims.

## Deployment notes

Upload `dist/`. Ensure the host serves `404.html` for unknown URLs. Set the real `siteUrl`, rebuild, then submit `/sitemap.xml` to Search Console. Re-review the compliance page date and content whenever GOV.UK guidance changes.
